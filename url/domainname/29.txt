### 1. **域名转移服务的关键要素** (续)
- **转移条件**：
  - 域名注册或上次转移超过60天（ICANN政策，防止未经授权的转移）。[](https://www.icann.org/resources/pages/name-holder-faqs-2017-10-10-en)
  - 域名未过期或处于赎回期（Redemption Period）。
  - 域名解锁（禁用Registrar Lock）。
  - 提供EPP授权码（也称Auth Code或Transfer Key），由当前注册商提供。
  - 部分TLD（如`.uk`）使用IPS Tag而非EPP码。
- **转移流程**：
  1. 确认域名符合转移条件（解锁、获取EPP码、更新WHOIS联系信息）。
  2. 在新注册商处发起转移请求，输入EPP码。
  3. 确认转移（通过注册人邮箱或新注册商的控制面板）。
  4. 旧注册商放行（通常5-7天，部分支持手动加速）。
  5. 转移完成，更新DNS记录以避免服务中断。
- **关键考虑**：
  - **隐私保护**：转移时可能需暂时禁用WHOIS隐私，确保接收授权邮件。
  - **DNSSEC**：转移后需重新配置DS记录，确保DNS安全。
  - **SSL/CT**：确保证书续期和CT日志监控无缝衔接。
  - **域名监控**：监控DNS/WHOIS变化，防止仿冒域名。
  - **服务中断**：若使用旧注册商的默认DNS，需提前配置新DNS以避免网站/邮件中断。
- **转移时间**：通常30分钟至5-15天，取决于旧注册商响应速度和TLD要求。[](https://domains.squarespace.com/transfer-a-domain)[](https://www.godaddy.com/domains/domain-transfer)[](https://www.dynadot.com/domain/transfer)

### 4. **防止域名劫持的作用**
- **WHOIS隐私保护**：隐藏个人信息，防止社会工程学攻击窃取EPP码或账户。[](https://www.cloudflare.com/learning/dns/how-to-transfer-a-domain-name/)

- **域名监控**：监控DNS/WHOIS变化，检测仿冒域名（如CSC的SOC团队）。[](https://www.namecheap.com/domains/transfer/)
- **转移安全**：
  - 使用2FA保护账户，防止未经授权的转移。
  - 启用Registrar Lock，高级用户可考虑Registry Lock（如CSC MultiLock）。
- **综合防护**：隐私保护+DNSSEC+SSL/CT+域名监控+锁机制，降低劫持风险。

### 5. **最佳实践**
- **准备转移**：
  - 确认域名超过60天且未过期，解锁并获取EPP码：

    whois example.com  # 检查注册时间和锁状态

  - 更新WHOIS联系邮箱，确保接收授权邮件。[](https://www.cloudflare.com/learning/dns/how-to-transfer-a-domain-name/)
  - 备份DNS记录（如A、MX、TXT），避免服务中断。[](https://dnsimple.com/how-to-transfer-a-domain-without-downtime)
- **选择注册商**：
  - 优先Cloudflare（成本价、一键DNSSEC）、Namecheap（低价、免费隐私）或Porkbun（促销价）。
  - 大型企业选择CSC DomainSec（高级安全、SOC支持）。
- **启用DNSSEC**：
  - 转移后在新注册商启用DNSSEC，验证信任链：
    ```bash
    dig example.com DS +dnssec
    ```
- **SSL/CT监控**：
  - 使用Let’s Encrypt（Cloudflare、Namecheap）自动续期SSL。
  - 配置CertSpotter监控CT日志，检测伪造证书：
    ```bash
    openssl s_client -connect example.com:443 -showcerts
    ```
- **配置CAA记录**：
  - 限制证书颁发者：
    ```text
    example.com. IN CAA 0 issue "letsencrypt.org"
    ```
- **账户安全**：
  - 启用2FA（推荐Google Authenticator）。
  - 使用专用邮箱和强密码（12+字符，密码管理器存储）。
- **域名监控**：
  - 使用DomainTools或Bolster AI监控DNS/WHOIS变化。
  - 检测仿冒域名（如`examp1e.com`）。
- **避免中断**：
  - 若使用旧注册商DNS，提前在新注册商配置DNS记录（如Namecheap FreeDNS）。[](https://www.namecheap.com/domains/transfer/)
  - 转移后验证网站/邮件服务：
    ```bash
    ping example.com  # 检查DNS解析
    ```

  - 使用DNSViz（dnsviz.net）检查DNSSEC。
